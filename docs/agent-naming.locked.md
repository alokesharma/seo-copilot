## Two deliberate departures from ChatSEO's labels
- **Page speed, not Core Web Vitals.** We measure crawl response time. Core Web Vitals
  are field metrics from real Chrome users and we have no source for them; their label
  would be a false claim.
- **Content decay carries the verdict.** ChatSEO's lists decay and stops. Ours ends each
  row in a decision, which is why the subtitle says so.
